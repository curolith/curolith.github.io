JSaturn is a hobby-project and my first front-end endeavor. Should you use JSaturn, be aware, that I am not
experienced in writing secure front-end applications. Furthermore, this project is still in its development stage.

highlight.js</a>). <br>
**Any code you execute has full console power.** <br>
**Data saved (on your device's local storage) might be accessible to other applications.** <br>
Do not execute code you don't understand. Do not save sensible data in JSaturn. <br>
I take no responsibility for the effects of code executed via JSaturn. Only use JSaturn if you are aware of the
risks and consequences.
